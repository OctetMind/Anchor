What this is

Anchor is a private chat app built for an AuDHD brain: complete one-shot answers, literal language, no pop-quiz follow-ups, and controls for how the AI behaves.

Privacy

Your API keys and chats are stored only in this browser. Chats live in IndexedDB (a large local database); settings stay in localStorage. Optionally lock your API key behind a passphrase so it's stored encrypted (Settings → AI). Nothing is sent anywhere except direct requests to the AI provider you choose. No analytics, no accounts, no server.

Voice input (mic button) uses your browser's built-in speech recognition — in Chrome/Edge that means Google's speech servers process the audio. The button hides itself if your browser can't do it. Read-aloud uses your device's built-in voices.

Phone

Android: open the menu → Install on this device, or your browser menu → “Install app”.

iPhone: Safari → Share button → Add to Home Screen. It then runs full-screen like a native app.

Hand to know

  • Everything saves automatically — there is no save button.
  • Every message has copy / retry / edit buttons.
  • Keyboard: Ctrl+K (or ⌘+K) = new chat. Ctrl+F = search all chats. Esc closes menus.
